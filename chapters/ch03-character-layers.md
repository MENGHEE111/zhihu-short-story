# Chapter 3：Character 层（人物的灵魂）

> 原书第 6, 8, 12 章。Plot 和 Character 交替螺旋的后半部分。**原书明确说了"没什么比人物更重要"**——这是雪花法和其他写作法最大的区别。

## Core Idea

人物不是"故事的工具人"，而是**故事本身的发动机**。戈德里洛克一开始写了个平面反派（"他就是个彻头彻尾的恶棍"），熊贝比逼她把反派也写成有血有肉的人。原书第 19 章完整演示了人物塑造的三层递进：

1. 一页纸人物介绍（价值观、抱负、目标、矛盾、顿悟、一句话、一段式）
2. 人物秘事 / backstory
3. 人物宝典（物理细节 + 性格）

**Plot 和 Character 必须交替扩展**——先有 Plot 的一句话，再有 Character 的一段简介；再有 Plot 的一段式，再有 Character 的秘事……如此螺旋上升。你**不能先写完所有 Plot 再回头写 Character**，也不能反过来。

## Character 层 1：一页纸人物介绍（原书第 6 章）

原书给戈德里洛克（主角）写的人物介绍：

```
角色：女主角/反派（她是自己最大的敌人）
价值观：
  - 没有什么比做自己喜欢做的事更重要
  - 没有什么比别人对自己的评价更重要
  - 没有什么比做正确的事更重要
抱负：成为伟大的小说家
目标：完成小说第一稿
矛盾：不知道从何下手，担心自己不是这块料，介意别人的看法
顿悟：作为一个小说作者相信自己的直觉
一句话概括：一个年轻女人梦想写小说，但是担心没人会喜欢她的作品
一段式概括：戈德里洛克一直想写一部小说，可是家里人都说这个梦想"不切实际"……（后续）
```

**关键发现**：每个人物的"一段式概括"里**也包含自己的三幕式**——这是 Plot 和 Character 对接的桥梁。当你把主角的三幕式、反派的三幕式、催化剂的三幕式**交叉碰撞**时，完整故事就自然长出来了。

## Character 层 2：人物秘事（原书第 8 章）

原书第 8 章标题就是"人物秘事"——backstory。回答三个核心问题：

1. **他/她为什么是现在这个样子？**（童年创伤/重大选择/失去/得到）
2. **他/她藏着什么秘密？**（这个秘密在剧情里的功能是什么）
3. **他/她最怕别人知道什么？**（这是塑造张力的关键——一个怕被发现的秘密比一个已经被发现的秘密更有重量）

原书给大灰狼（出版代理人/被诬陷的凶手）写的 backstory：
> 大灰狼从小生活在混乱环境中。少年时目睹叔叔被村民处以私刑。十九岁时遭人陷害被控谋杀，蹲了六年大牢。出狱后靠监狱图书馆自学，之后成为出版代理人。

**原书重要提醒**：**反派也必须有秘事**。戈德里洛克一开始想跳过反派的 backstory，熊贝比说：一个没有秘事的反派是一个**没有动机的反派**——他为什么做坏事？你必须给他一个让读者能理解、甚至能同情的理由。小猪（那个杀人的富商）的 backstory 是"出身贫困白手起家，不择手段是生存习惯"——他不是天生的坏人，是经历把他塑造成这样的。

## Character 层 3：人物宝典（原书第 12 章）

最细的人物档案——**物理细节 + 性格细节 + 生活细节**。给戈德里洛克写的部分：

```
年龄：30岁
身高：1.65 米
体重：52 千克
民族/血统：北欧
头发：金色
眼睛：蓝色
性格类型：温和型行动派
兴趣爱好：阅读、写作
最喜欢的书：肯·福莱特和杰克·希金斯
住所：市郊房子，三个卧室
家庭情况：已婚，一儿一女
最可怕的童年记忆：森林里迷路进了三只熊的小屋
性格中最弱的一面：顾忌别人的看法
最深的恐惧：写完小说没人愿意看
人物如何发生变化：变得自信，相信自己的直觉
```

**知乎短篇适配**：人物宝典**可以大幅简化**——短篇不需要这么多物理细节。保留：价值观、矛盾、顿悟、最深恐惧、最大愿望、人物变化方向。

## Worked Example（原书第 19 章完整人物塑造）

原书作者为自己的商业寓言写了 8 个人物的完整介绍（戈德里洛克、熊贝比、大灰狼、小猪、小小猪、哈巴德太太、罗宾·汉、熊老爹）。每个人物都有：价值观、抱负、目标、矛盾、顿悟、一句话、一段式。

## Anti-patterns

- **跳过反派 backstory**：你的反派必须有一个合理的、可理解的动机——哪怕他做的事是坏的，他做事的理由不能是"因为他坏"。
- **先写好主角再忘记其他人物**：原书强调"每个人物都必须有自己的三幕式弧线"。
- **让人物为情节服务**：情节应该**从人物的选择里生长出来**，不是你先想一个情节，再让人物去演。戈德里洛克的故事是从她"怕别人评价但又想写小说"这个矛盾里长出来的，不是作者先想了一个研讨会枪击案然后塞给她。
