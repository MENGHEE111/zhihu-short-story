# Chapter 2：Plot 层（故事的骨架）

> 原书第 3, 5, 7, 9, 13 章。Plot 和 Character 交替螺旋的前半部分。

## Core Idea

故事的 Plot 层是从一个 25 字钩子**一路扩展**到完整大纲的过程。每一层都比上一层更长，但都**围绕同一个核心冲突**。原书明确了 5 个 Plot 层（短篇可以合并其中 2 个）。

## Plot 层 1：一句话概括（原书第 3 章）

**不超过 25 个字**，让读者一眼就知道故事的卖点。原书给的例子：
> 一个年轻女人梦想写小说，但是担心没人会喜欢她的作品。（21 字）

原书的弗雷德里克·福赛斯例子更具体：
> 法国恐怖分子雇职业杀手暗杀戴高乐。（21 字）——你能"看到"画面

**知乎短篇三个黄金钩子模式**（从原书方法延伸）：
- **悬念型**：结尾留一个还没解答的问题 → "我爸死那天写的信，被我奶奶锁了十五年。"
- **反常识型**：打破读者预期 → "我在自己的葬礼上，看见了不该来的人。"
- **情感型**：戳中痛点 → "分手三年后，我收到了前男友的结婚请柬，附了张我的黑白照。"

## Plot 层 2：一段式概括（原书第 5 章，也就是三幕式+三次灾难）

原书第 5 章用"灾难"概念构建：**一句话 → 五句话，每一句对应三幕式的一个节点**。这五句话的精确结构是：

```
1. （日常钩子）主角正常状态 + 那个"不对劲"的画面
2. （第一次灾难）打破日常，被迫入局——主角想要什么，但被阻止
3. （第二次灾难 + 道德前提转折）原以为的对的其实错了；局面更糟；主角的内心开始分裂
4. （第三次灾难）最糟时刻，主角必须做最终选择（没有中间选项）
5. （结局/反转）给画面，不给说教；读者自己品
```

**道德前提转折**是这里的关键（原书第 9 章）：
- 原来我以为：X 是对的
- 后来我发现：X 不是对的，或者 X 有另一面
- 这让主角的行动逻辑变了，故事才有深度

## Plot 层 3：一页纸大纲（原书第 7 章）

把五句话的骨架**扩成一页纸完整故事**（约 300-600 字）。原书作者说这是"最重要的一步"——只有写完这一页，你才真正知道"这到底是个什么故事"。

**扩展方式**：五句骨架里的每一句扩成一个段落，把已经写好的人物（Character 层）自然嵌进去。一个陌生人读完应该能看懂完整故事。

## Plot 层 4：四页纸完整大纲（原书第 11 章）

原书第 11 章的完整大纲（约 4 页）。**知乎短篇可以跳过**——作者自己在第 19 章也说了"这个故事由于篇幅较短，故而不需要写完整大纲"。

## Plot 层 5：第三次灾难 + 最糟时刻（原书第 13 章）

第三次灾难是**主角被逼到绝境**的时刻——没有中间选项，必须做一个会改变一切的选择。原书强调这和第二次灾难不同：第二次是"道德前提转折"（主角内心分裂），第三次是"行动上必须选择"（主角必须做点什么）。

## Anti-patterns

- **钩子太长**：超过 25 字的钩子就是废话。原书用福赛斯的《豺狼的日子》示范了为什么短才好——读者能瞬间想象画面。
- **没有道德前提转折**：只有"坏事发生了"但没有"主角的认知被颠覆"的故事，读者看完会觉得"哦就这？"
- **三次灾难变三次挫折**：灾难不是"主角被老板骂了""主角忘带钥匙了"，是**能把主角逼到绝境的事**——威胁生命、威胁尊严、威胁最爱的人。
