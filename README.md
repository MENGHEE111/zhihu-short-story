# zhihu-short-story

基于雪花写作法（Snowflake Method）改造的 Trae Skill，引导知乎短篇小说（3000-10000 字）的创作。

## 为什么做这个

原版雪花写作法有 10 步，面向长篇小说。知乎短篇节奏快、篇幅短，因此将 10 步压缩为 7 步，保留"从极简到丰富"的迭代思路，同时融入知乎平台的钩子、节奏、结尾规则。

## 7 步流程

1. **钩子**（≈ 雪花法第 1 步）— 25 字内，知乎三种黄金模式
2. **五句骨架**（雪花法第 2 步）— 三幕 + 三次灾难升级
3. **人物卡**（雪花法第 3+5 步）— 1-3 人，砍掉配角建档
4. **场景清单**（雪花法第 8 步）— 3-6 场景
5. **分场景梗概**（雪花法第 4+6 步）— 每个场景 2-4 句
6. **逐场景写正文**（雪花法第 10 步）— 融入知乎铁律
7. **标题 + 导语** — 知乎回答特有环节

## 安装

```bash
# 复制到 Trae 全局 skills 目录
cp -r zhihu-short-story ~/.trae-cn/skills/
```

## 使用

在 Trae 中说"帮我写一篇知乎短篇"、"我有个灵感想写成短篇小说"或提到 `zhihu-short-story` 即可触发。
